# Tienda Alpi

[![CI](https://github.com/matiasfauda23/tienda-alpi/actions/workflows/ci.yml/badge.svg)](https://github.com/matiasfauda23/tienda-alpi/actions/workflows/ci.yml)

Catálogo web de Tienda Alpi (mates térmicos, termos, vasos y bombillas) con precios por escala de cantidad y pedidos por WhatsApp.

## Stack

- **Frontend:** Next.js + TypeScript + Tailwind CSS
- **Backend:** NestJS + TypeScript + Prisma
- **Base de datos:** PostgreSQL
- **Monorepo:** pnpm workspaces
